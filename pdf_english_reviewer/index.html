Review policy

          
Custom Review: Runs only the selected external engines, Team Manual Standard, and selected external publishing standards.

          
Review scope: Full Review uses the selected local style, standard, terminology, and Ollama context checks. Headings, labels, TOC leaders, trademark markers, and general whitespace are excluded.

          
Context: Full Review requires Ollama Local and records metadata-only outcomes for every reviewed unit, including zero-finding results.

          
The Reviewer does not download or install engines. See SETUP_GUIDE.md for approved offline setup steps.
