CHAPTER 01
Tool Overview

1.1 What is AFM Journal Search Tool?

An integrated research tool designed to systematize Chapter 1 Introduction writing for AFM measurement mode manuals. It consolidates journal searching, evaluation, and organization into a single HTML file.

Problems this tool solves
Inconsistent search criteria, no unified IF·citations·equation evaluation, and repeated keyword-search-notes-draft cycles — all solved in one place.

1.2 Key Features

Single HTML File
No install. Opens instantly in Chrome/Edge. Most features work offline.
API Auto-Search
CrossRef + Unpaywall APIs for automatic keyword-based search and real-time PDF availability check.
Auto Quality Scoring
0–100 score calculated from IF, citations, equation count, and physics/circuit content.
Batch ZIP Export
Metadata, report, draft template, checklist, and PDFs — all in one ZIP.

CHAPTER 07
Frequently Asked Questions

Q1. Can I use it without internet?

Keyword setup, manual registration, list management, and ZIP (without PDFs) work offline. Auto-search, DOI fetch, and PDF download require internet.

Q2. Auto search returns no results.

Check: email entered, keywords selected (blue), internet connected, try broader keywords.

Q3. Some journals show No PDF.

Journal is paywalled. Use Sci-Hub button with DOI or access through institutional account.

Q4. ZIP is very slow.

Uncheck "pdf/ folder" for much faster ZIP generation without PDFs.

Q5. Data disappears when browser closes.

Yes — current version uses session memory. Always export to ZIP before closing.
